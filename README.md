# Saltwind Inn

Coastal inn landing on a working harbour. Linen, kelp, salt gold, and a serif masthead. Light-custom: logo, colours, fonts, copy, and section on/off. Distinct from spa/thermal templates.

Live demo: https://saltwind.little.website/

## Features

- Coastal inn landing on a working harbour
- Light-custom: logo, colours, fonts, and copy
- Section on/off for hero, rooms, stay, table, harbour, and contact
- Linen, kelp, and salt gold palette
- Serif masthead (Newsreader)
- Distinct from spa and thermal templates
- Fully responsive Astro SSG

## Design

Typography:
- display: Newsreader
- ui: Karla

Colors:
- Harbour: #0e3a4a
- Salt gold: #c9a36a
- Linen: #f6f1e8
- kelp: #3f6b5e

## Customization

Light-custom: logo, colours, fonts, copy, and section on/off.

Edit src/data/site.ts and CSS variables in src/styles.

Page sections:
- Hero
- Rooms
- Stay
- Table
- Harbour
- Contact

Use cases:
- Coastal inns
- Boutique lodging
- Harbour hotels
- Hospitality stays

## Stack

Astro 5 SSG, CSS variables, TypeScript, Vite.
Fonts: Newsreader, Karla
